# 品控中心 · 数据概览

> 页面入口：品控中心 → 数据概览（侧边栏第一项）
> 涉及文件：src/pages/quality/QualityCenter.tsx、qcCenterCharts.tsx、qcCenterData.ts、qcCenter.css

## 1. 数据总览卡片

**需求**：顶部一屏呈现核心盘子。

- 四张卡：监控系列编码数、风险品数量（含风险占比 = 风险品 ÷ 监控编码数）、监控编码订单量（原名「订单量」，后按需求更名以明确口径）、聊天问题命中次数（含聊天风险率 = 命中次数 ÷ 周期订单量）。
- 支持时间范围切换：今日 / 近7天 / 自定义（日期区间弹层），各区块范围独立互不干扰。

## 2. 问题类型占比

**需求**：按问题类型（质量问题、描述/宣传不符、包装破损、少发、物流问题、服务类问题、价格/活动类问题、错发）展示命中分布。

- 左侧类型卡片（数值 + 占比），右侧环形图（中心为问题总数）。
- 环形图图例双行展示：占比 + 聊天风险率（聊天问题命中次数 ÷ 订单量）。
- 点击类型卡 → 跳转监控列表并自动带入该类型筛选（草稿/生效同时写入）。

## 3. 问题涉及部门占比

**需求**：问题按责任部门维度分布（品质、运营、仓库、快递、快递/品质、客服）。

- 六张部门卡（色点 + 数值 + 占比），与类型卡同款样式。

## 4. 问题趋势与 TOP 问题商品

**需求**：整体置入白底模块（与上方模块样式一致），左侧趋势图 + 右侧 TOP 榜。

- 趋势图展示全部 8 类问题曲线；图例可点击隐藏/显示，Y 轴自动重缩放。
- 右轴订单量虚线对比曲线（「订单量（右轴）」图例可切换显隐）。
- 时间范围：今日 / 近7天 / 自定义。
- TOP 问题商品榜支持「按退款率 / 按聊天风险率」切换；行点击打开该编码详情；行内展示退款率/聊天风险率与垃圾品状态标签（垃圾品 / 疑似垃圾品 / 正常）。

## 5. 优化数据概览

**需求**：在「问题涉及部门占比」与「问题趋势」之间增加优化任务概览模块，样式与其它模块一致，支持时间选择，点击跳转优化任务列表对应状态。

- 独立白底面板，头部右侧今日 / 近7天 / 自定义切换。
- 六张状态卡（待认领 / 待优化 / 优化中 / 待审核 / 优化完结 / 拒绝），按登记日期窗口统计数量 + 占比，样式同部门卡，hover 变深、指针手势。
- 点击状态卡 → 切换至优化任务页且状态 tab 自动激活对应状态。
- 数据与优化任务列表共享同一状态源：列表内分配/拒绝/删除后概览计数同步变化（为此将 tasks 与 statusTab 状态上提至品控中心统一持有，OptTaskView 改为受控组件）。
