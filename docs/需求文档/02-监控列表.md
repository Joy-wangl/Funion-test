# 品控中心 · 监控列表

> 页面入口：品控中心 → 监控列表（侧边栏第二项）
> 涉及文件：src/pages/quality/QualityCenter.tsx、qcParts.tsx、qcTables.tsx、qcCenterData.ts、qcCenterCharts.tsx、qcCenter.css

## 1. 筛选表单

- 条件：搜索（店铺 / 系列编码 / 商品编码）、平台、问题类型、问题涉及部门、责任部门、时间范围（自定义时出日期区间）。
- 交互语义：草稿/生效分离——修改条件不即时过滤，点「查询」生效、「重置」恢复默认；与全项目其它模块一致。
- 布局：条件与按钮同排，查询/重置统一右侧（详见 04-全局交互规范）。

## 2. 系列主表

列结构（按维度排列）：系列编码（编码 + 系列名双行）｜订单量｜退款率｜售后单｜聊天风险｜聊天风险率｜上架平台｜命中问题类型｜问题涉及部门｜责任部门｜操作。

- 订单量/退款率/售后单/聊天风险列头带统一双箭头排序图标，激活方向主色高亮。
- 上架平台：平台标签组（抖音/快手/拼多多/淘宝/天猫/京东）。
- 命中问题类型：全量标签换行展示（类型色 + 命中数），不横向滚动。
- 问题涉及部门：部门标签组。

## 3. 责任部门

**需求**：系列编码绑定唯一责任部门，支持全局修改与双维度筛选。

- 默认值 = 该系列命中问题数最多的部门（不受筛选影响）。
- 「修改责任部门」弹层修改后 localStorage 全局持久化，标签高亮表示存在人工覆盖。
- 筛选区「问题涉及部门」（实际命中）与「责任部门」（绑定）两个独立筛选维度。

## 4. 平台矩阵（行展开）

- 展开系列行 → 各平台数据矩阵：订单量/退款率/售后单/聊天风险/聊天风险率/命中问题类型 + 下属商品编码子表。
- 矩阵操作列：聊天记录（会话弹层 SessionCard）、趋势图（平台维度）。
- 矩阵头不换行、标签换行全展示，消除横向滚动。

## 5. 趋势图弹层（双入口）

**需求**：系列维度与平台维度均可查看周期内指标趋势。

- 入口一：主表操作列「趋势图」（系列维度）；入口二：平台矩阵操作列「趋势图」（当前平台维度）。
- 弹层（Modal xl 规格，1080px）：指标 tab 切换（订单量/退款率/售后单/聊天风险数/聊天风险占比），单大趋势图 + 悬浮气泡展示具体数值（hover 竖直参考线 + 深色气泡，右缘自动翻转）。
- 周期切换：昨日（小时粒度）/ 前3日 / 前7日 / 自定义（日期区间）。

## 6. 优化效果区间带（编码优化数据）

**需求**：监控列表要加上编码优化相关数据；优化效果不是独立 tab，而是在各个指标类型下展示优化过程中指标的变化（优化开始 → 优化完结）。

- 数据层：OptTask 增加 optStartAt（进入优化中）/ optEndAt（优化完成，提交审核或完结）。
- 趋势图所有指标 tab 叠加优化区间带：
  - 优化中任务：起点虚线 + 色带延伸至右缘，顶部标签「方向·进行中」；
  - 已完成任务：起点虚线 + 终点实线色带，顶部标签「方向·完成」；
  - 区间带颜色取任务状态色；起点早于当前窗口自动左钳制，完全出窗不渲染。
- 图下优化过程记录列表：色点 + 优化方向 + 优化类型 + 区间（08/13 → 进行中）+ 状态；无记录不显示。
- 系列/平台两个入口均按系列编码关联优化任务。

## 7. 验证结论

- tsc 通过；浏览器实测：筛选草稿/生效、排序、责任部门修改持久化、矩阵下钻、趋势双入口、五指标 tab 区间带稳定渲染、周期切换无报错，控制台无 error。
