# 智能运营中心 · 任务中心

> 页面入口：智能运营中心 → 任务中心（侧边栏）
> 涉及文件：src/pages/ops-center/TaskCenterPage.vue、TaskParentList.vue、TaskSubFlatList.vue、TaskSubDetail.vue、data.ts、tcSteps.ts、TcNodeCell.vue、TcStepsCell.vue、TcRiskModal.vue、TcRange.vue、colFields.ts、ColFieldPop.vue、publishStore.ts、PublishProgress.vue、moveData.ts、OpsCenter.vue、OpsCenter.css

## 1. 需求背景与目标

**背景**：蜂联平台商品发布、铺货、调价、下架等操作均以异步任务形式执行，运营人员需要一个统一入口查看所有任务的执行进度、成功/失败分布，并对失败任务进行重试、对待确认任务进行人工审核。

**目标**：
- 提供批次视角（一级聚合）和详情视角（一品一店一任务）两种查看维度
- 支持按任务类型、状态、平台、店铺、创建人等多维度筛选
- 失败任务支持单条/批量重试，风控待确认任务支持通过/拒绝
- 节点级执行进度可视化，失败原因可追溯

## 2. 用户故事

| 角色 | 场景 | 期望 |
|------|------|------|
| 运营专员 | 发起一批商品发布后 | 在任务中心看到执行进度圆环，实时了解成功/失败/执行中数量 |
| 运营专员 | 发现某批次有失败任务 | 按「执行失败」tab 筛选，查看失败原因大类，批量重试 |
| 运营专员 | 任务命中风控管控商品 | 收到待确认状态，人工判断后通过或拒绝 |
| 运营主管 | 查看团队任务执行情况 | 按创建人筛选，了解各成员任务量与成功率 |
| 运营专员 | 从自动化中心发起搬家任务 | 在任务中心通过「自动化任务」筛选溯源到对应批次 |

## 3. 功能需求

### 3.1 双视角切换

任务中心支持两种查看模式，右上角切换按钮控制：

| 模式 | 说明 | 默认 |
|------|------|------|
| 按任务详情 | 扁平列表，一品一店一任务，展示全部子任务 | 否 |
| 按任务批次（默认） | 一级批次列表，点击「查看详情」钻入子任务 | 是 |

钻入批次详情时，头部显示批次元信息（创建人、创建时间、任务类型标签），并提供返回按钮回到批次列表。

### 3.2 任务类型

共 9 种任务类型，每种有独立标签色：

| 任务类型 | 标签色 | 节点流程 |
|----------|--------|----------|
| 快速铺货 | #4f7cff | 获取链接信息 → 校验管控商品 → 定价策略计算 → 商品发布店铺 |
| 批量铺货 | #7c5cff | 同上（4 节点） |
| 商品发布 | #1f9d55 | 同上（4 节点） |
| 批量调价 | #ff9a2e | 商品信息校验 → 利润测算 → 商品信息发布（3 节点） |
| 批量涨价 | #e6455c | 同上（3 节点） |
| 批量下架 | #0ea5e9 | 获取商品信息 → 商品下架（2 节点） |
| 自动搬家 | #14b8a6 | 同发布类（4 节点） |
| 自动下架 | #64748b | 同下架类（2 节点） |
| 自动发布 | #eb2f96 | 同发布类（4 节点） |

批次列表顶部类型行：「全部」+ 9 种类型 chips，点击收敛列表。选定具体类型后「任务类型」列自动隐藏（信息冗余）。

### 3.3 任务状态

**批次状态（ParentStatus）**：

| 状态值 | 文案 | 聚合规则 |
|--------|------|----------|
| queued | 队列中 | 全部子任务均为 queued |
| running | 执行中 | 其余情况 |
| done | 已完成 | 全部子任务终结（success/failed） |

**子任务状态（SubStatus）**：

| 状态值 | 文案 | 说明 |
|--------|------|------|
| queued | 队列中 | 等待执行 |
| running | 执行中 | 正在执行 |
| success | 已完成 | 执行成功 |
| failed | 执行失败 | 节点失败或店铺发布失败 |
| confirm | 待确认 | 命中风控管控商品，需人工审核 |

**状态聚合规则（taskStatusOf）**：
1. 统一节点失败（failStep 存在）→ failed
2. 全部店铺 queued → queued
3. 任一店铺 failed → failed
4. 全部店铺 success → success
5. 其余 → running

### 3.6 节点状态可视化

**TcNodeCell 组件**：展示任务执行的节点流程进度。

节点状态样式：

| 状态 | 圆点 | 文案 |
|------|------|------|
| ok | 绿色实心 | 成功 |
| run | 蓝色旋转 | 执行中 |
| fail | 红色实心 | 失败 |
| confirm | 橙色实心 | 待确认 |
| wait | 灰色空心 | 待执行/– |

悬浮时间线弹窗：贴单元格右侧展开，展示各节点详细状态与校验管控商品节点的通过/失败/待确认计数。

### 3.7 任务操作

#### 单条操作

| 操作 | 显示条件 | 行为 |
|------|----------|------|
| 详情 | 首节点未失败 且 非待确认 | 跳转商品创建详情页（按平台映射：微信视频号小店→createVideo、京东→createJm、其余→createTaobao） |
| 重试 | 状态为 failed | 清除失败节点 → 1.2s 模拟执行 → 全部 success，同步批次聚合 |
| 通过 | 状态为 confirm | 弹出确认弹窗「命中我司风险管控商品，请确认是否继续上架？」→ 清风险态进入执行中 |
| 拒绝 | 状态为 confirm | 弹出确认弹窗「审核拒绝后发布任务失败，是否确认拒绝发布」→ 标记失败（failStep=1） |

#### 批量操作

| 操作 | 显示条件 | 行为 |
|------|----------|------|
| 批量重试 | 全部/执行失败 tab | 勾选 failed 行 → 逐条 retrySub |
| 批量确认 | 全部/待确认 tab | 勾选 confirm 行 → 逐条 confirmSub |
| 批量拒绝 | 全部/待确认 tab | 勾选 confirm 行 → 逐条 rejectSub |

批量操作按钮随状态 tab 收敛，条数实时反映已勾选数。

### 3.8 风控二次确认

**TcRiskModal 组件**：
- 展示商品名称 + 风险说明（riskReason）
- 操作按钮：「取消任务」/「继续上架」
- 通过 → confirmSub → 清风险态、校验节点全通过、店铺开始发布
- 拒绝 → rejectSub → 标记失败（failStep=1）、校验节点失败计数、店铺全部 failed

### 3.9 失败原因分类

**失败大类（TC_FAIL_CATS）**：店铺限制、编码问题、系统超时、模板问题、类目资质、接口报错、价格库存、店铺授权、素材图片、页面异常、状态冲突、其它

**具体原因词表（TC_FAIL_REASONS）**示例：
- 店铺限制：每日发品/提审/上架次数达上限、店铺需开通运费险、在架商品数达上限、类目商品数量超限额、保证金不足、店铺不具备类目发布权限
- 编码问题、系统超时等各有对应具体原因

失败原因按任务类型分组：调价类/下架类有专属话术，chips 按类型收敛。

## 4. 数据模型

### 4.1 批次任务（ParentTask）

```typescript
interface ParentTask {
  id: number;
  creator: string;              // 创建人
  createTime: string;           // 创建时间
  type: string;                 // 任务类型（9 种枚举）
  status: ParentStatus;         // queued | running | done
  channel: string;              // 渠道：智能 / 蜂联
  pubWay: string;               // 发布方式：蜂联发布 / 插件发布
  shops: number;                // 店铺数量
  links: number;                // 链接数量
  success: number;              // 成功子任务数
  failed: number;               // 失败子任务数
  running: number;              // 执行中子任务数
  startTime: string;            // 执行开始时间
  endTime: string;              // 执行结束时间
  subs: SubTask[];              // 子任务列表
  pubFor?: string;              // 个人商品库商品链接（关联发布任务抽屉联动）
  mvId?: string;                // 自动化任务ID（溯源自动化中心）
}
```

### 4.2 子任务（SubTask）

```typescript
interface SubTask {
  id: number;
  taskId: string;               // 全局唯一任务ID（字符串避免雪花ID精度丢失）
  templateNo: string;           // 模板编号
  name: string;                 // 商品名称
  thumb: string;                // 缩略图
  linkId: string;               // 链接商品ID
  sourceShop?: string;          // 来源店铺（自动搬家）
  sourceProductId?: string;     // 来源商品ID（自动搬家）
  publisher?: string;           // 发布人
  status: SubStatus;            // queued | running | success | failed | confirm
  failStep?: number;            // 失败节点索引（0 起）
  verify?: {                    // 校验管控商品节点结果
    total: number;
    pass: number;
    fail: number;
    pending: number;
  };
  riskReason?: string;          // 风险说明（confirm 状态）
  shops: ShopResult[];          // 店铺发布结果（一品一店一任务，长度恒为 1）
  startTime: string;
  endTime: string;
}
```

### 4.3 店铺结果（ShopResult）

```typescript
interface ShopResult {
  platform: string;             // 平台
  shop: string;                 // 店铺名
  status: SubStatus;            // 店铺级状态
  reason: string;               // 失败原因
  retried: boolean;             // 是否已重试
  startTime: string;
  endTime: string;
}
```

## 5. API 接口定义

> 当前为前端原型，数据为 Mock。以下为正式环境需对接的接口规范。

### 5.1 查询批次列表

```
GET /api/task-center/parents
```

**请求参数**：

| 参数 | 类型 | 说明 |
|------|------|------|
| status | string | 批次状态：all/queued/running/done |
| type | string | 任务类型，空=全部 |
| platform | string | 发布平台 |
| creator | string | 创建人（模糊） |
| shop | string | 店铺名称（模糊） |
| pubWay | string | 发布方式 |
| linkId | string | 链接商品ID（模糊） |
| taskId | string | 任务ID（模糊） |
| mvId | string | 自动化任务（名称/ID 匹配） |
| retrying | string | 是否重试中 |
| startTime | string | 创建时间起（ISO） |
| endTime | string | 创建时间止（ISO） |
| page | number | 页码 |
| pageSize | number | 每页条数 |
| sortBy | string | 排序字段 |
| sortOrder | string | asc/desc |

**响应**：

```json
{
  "code": 0,
  "data": {
    "total": 74,
    "list": [ParentTask]
  }
}
```

### 5.2 查询子任务列表

```
GET /api/task-center/subs
```

**请求参数**：同批次列表 + 以下额外参数：

| 参数 | 类型 | 说明 |
|------|------|------|
| parentId | number | 批次ID（钻入时传入） |
| failCat | string | 失败原因大类 |
| compete | string | 竞品链接（模糊） |

### 5.3 重试任务

```
POST /api/task-center/subs/{id}/retry
```

**响应**：更新后的 SubTask 对象

### 5.4 通过风控确认

```
POST /api/task-center/subs/{id}/confirm
```

### 5.5 拒绝风控确认

```
POST /api/task-center/subs/{id}/reject
```

### 5.6 批量操作

```
POST /api/task-center/subs/batch
```

**请求体**：

```json
{
  "ids": [1, 2, 3],
  "action": "retry" | "confirm" | "reject"
}
```

## 6. 交互规范

### 6.1 筛选区

- 查询条件与按钮同排右对齐布局
- 所有文本输入框带快捷清除钮（清空并立即重查）
- 占位文案统一 token：--color-placeholder #98a0b3/400
- 下拉选择统一使用 BubbleSelect 气泡样式，禁用原生 select

### 6.2 表格

- 表头与内容左对齐，列宽均匀分布
- 操作列动作不超过三个时直接平铺，不收纳「更多」
- 滚动容器默认隐藏滚动条，仅保留滚动交互

### 6.3 状态展示

- 批次列表状态列：SVG 圆环进度（完成数/总数百分比）+ 状态文案
- 详情列表节点状态：TcNodeCell 组件，主状态行 + 步进器 + 当前节点行
- 节点悬浮时间线热区 = 内容宽 fit-content，单元格空白不触发

### 6.4 批量操作

- 勾选框仅对 failed/confirm 行可用
- 批量操作按钮条数实时反映已勾选数
- 批量操作前需二次确认（删除类动作统一防误删）

### 6.5 视角切换

- 右上角「按任务详情」/「按任务批次」按钮切换
- 钻入批次详情时头部显示返回按钮 + 批次元信息
- 批次元信息：创建人 · 创建时间 + 任务类型彩色标签

## 7. 关联模块

| 模块 | 关联方式 |
|------|----------|
| 商品创建 | 子任务「详情」操作跳转对应平台创建子页（createTaobao/createVideo/createJm） |
| 自动化中心 | 自动搬家/自动下架/自动发布任务的 mvId 溯源到自动化中心-视频号自动化任务 |
| 个人商品库 | pubFor 字段关联「关联发布任务」抽屉，同源联动 |
| 全局消息 | 商品发布任务完成后通过 globalMsgData 通知跳转任务中心查看 |
| 发布进度面板 | publishStore.ts 管理发布任务列表，支持人工介入恢复、风控处理 |
