## 二、需求背景

蜂联平台商品发布、铺货、调价、下架等操作均以异步任务形式执行。运营人员需要一个统一入口查看所有任务的执行进度、成功/失败分布，并对失败任务进行重试、对待确认任务进行人工审核。

当前任务中心已上线批次列表视图，本次改版聚焦于：
1. 完善筛选维度，支持多条件组合精确定位任务
2. 补充详情列表视图，支持一品一店一任务粒度的节点进度可视化
3. 完善失败原因分类体系，支持按大类快速筛选失败任务
4. 补充批量操作能力，提升运营处理效率

## 三、业务目标

- 运营人员可在任务中心实时掌握各批次任务的执行进度（圆环进度 + 成功/失败/执行中计数）
- 支持按任务类型、状态、平台、店铺、创建人、时间范围等多维度筛选
- 失败任务支持单条/批量重试，风控待确认任务支持通过/拒绝
- 节点级执行进度可视化，失败原因可追溯到大类

## 五、业务流程

### 5.1 任务生命周期

```
创建批次 → 队列中(queued) → 执行中(running) → 已完成(done)
                                    ↓
                              子任务级别：
                              queued → running → success
                                           → failed（可重试）
                                           → confirm（待人工确认 → 通过/拒绝）
```

### 5.2 失败处理流程

```
子任务失败 → 展示失败原因大类 chip → 运营查看失败详情
    ↓
单条重试 / 批量重试 → 清除失败节点 → 重新执行 → 更新状态
```

### 5.3 风控确认流程

```
子任务命中风控 → 状态变为 confirm → 展示风险说明
    ↓
运营人工判断 → 通过（继续上架）/ 拒绝（标记失败）
```

#### 6.5.3 单条操作

| 操作 | 显示条件 | 行为 |
|------|----------|------|
| 详情 | 首节点未失败 且 状态非待确认 | 跳转商品创建详情页（按平台映射：微信视频号小店→createVideo、京东→createJm、其余→createTaobao） |

### 6.6 任务状态定义

#### 6.6.1 批次状态（ParentStatus）

| 状态值 | 文案 | 聚合规则 |
|--------|------|----------|
| queued | 队列中 | 全部子任务均为 queued |
| running | 执行中 | 存在 running/confirm 等非终态子任务 |
| done | 已完成 | 全部子任务均为 success/failed 终态 |

#### 6.6.2 子任务状态（SubStatus）

| 状态值 | 文案 | 说明 |
|--------|------|------|
| queued | 队列中 | 等待执行 |
| running | 执行中 | 正在执行 |
| success | 已完成 | 执行成功 |
| failed | 执行失败 | 节点失败或店铺发布失败 |
| confirm | 待确认 | 命中风控管控商品，需人工审核 |

#### 6.6.3 子任务状态聚合规则

1. failStep 存在 → failed（统一节点失败优先）
2. 全部店铺 queued → queued
3. 任一店铺 failed → failed
4. 全部店铺 success → success
5. 其余 → running

### 6.7 失败原因分类

#### 6.7.1 失败大类（12 类）

| 序号 | 失败大类 | 说明 |
|------|----------|------|
| 1 | 店铺限制 | 店铺维度的发品/上架限制 |
| 2 | 编码问题 | SKU 编码、规格相关异常 |
| 3 | 系统超时 | Worker 消息领取超时 |
| 4 | 模板问题 | 模板同步、保存、冲突异常 |
| 5 | 类目资质 | 类目预测、属性校验、资质缺失 |
| 6 | 接口报错 | 外部接口调用失败 |
| 7 | 价格库存 | 成本价、库存、价格测算异常 |
| 8 | 店铺授权 | 店铺未核身、账号无权限、店铺信息缺失 |
| 9 | 素材图片 | 素材图缺失、视频无效、图片不合法 |
| 10 | 页面异常 | RPA 页面操作异常 |
| 11 | 状态冲突 | 草稿冲突、审核撤销、结果未知 |
| 12 | 其它 | 未归类的失败 |

#### 6.7.2 具体失败原因（按大类枚举）

**店铺限制（6 条）**：
1. 每日发品、提审或上架次数达到上限
2. 店铺需开通运费险
3. 在架商品数达到上限或店铺不允许上架
4. 类目商品数量超过限额
5. 保证金不足导致上架受限
6. 店铺不具备类目发布权限

**编码问题（8 条）**：
1. SKU 系列编码不一致
2. SKU 缺少系列编码
3. SKU 规格名称超长
4. SKU 规格值匹配或校验失败
5. 调价 SKU 标识与规格不一致或无法匹配
6. SKU 商家编码含英文逗号
7. 在售 SKU 规格名称重复
8. 组合编码创建失败

**系统超时（1 条）**：
1. Worker 未领取消息，重投次数耗尽

**模板问题（6 条）**：
1. 同步母链接失败：数据流读取异常
2. 商品管理查询返回空结果
3. 母链接同步、获取或保存模板失败
4. 预留模板与平台或来源不一致
5. 源链接失效或商品不存在
6. 复制或保存模板失败：唯一键冲突

**类目资质（4 条）**：
1. 类目预测失败、类目缺失或不一致
2. 商品表单或属性校验不通过
3. 类目要求坏损包退、假一赔三等服务
4. 资质或许可证必填项缺失

**接口报错（8 条）**：
1. 聚水潭商品下架操作失败，未提供具体原因
2. 执行进程内存不足
3. 发布操作上下文读取失败
4. 对象映射编译异常
5. 外部接口返回 HTTP 404
6. 请求超时或连接、流读取异常
7. 外部请求发送失败
8. 数据库连接上存在未结束命令

**价格库存（3 条）**：
1. 成本价缺失或为零
2. 库存为零或库存数据异常
3. 销售价不高于成本或价格测算不通过

**店铺授权（3 条）**：
1. 店铺未核身，勾选框被禁用
2. 账号未持有目标店铺
3. 店铺信息缺失（店铺为空或无平台编码）

**素材图片（4 条）**：
1. 素材图缺失或上传异常
2. 视频无效或转换失败
3. 图片失效、尺寸或比例不合法
4. 媒体 URL 非法或多个 URL 逗号拼接

**页面异常（3 条）**：
1. 聚水潭页面未出现 SKU 表格
2. 发布页面或 RPA 卡控提示其它异常
3. 页面等待、元素定位或提交状态超时

**状态冲突（3 条）**：
1. 已有待审核草稿，无法调价或重复发布
2. 微信商品审核撤销或拒绝
3. 远端创建结果未知，系统阻断自动重发

**其它（1 条）**：
1. 任务状态失败，但未返回失败节点或错误说明

#### 6.7.3 失败原因按任务类型分组

| 分组 | 任务类型 | 专属原因 |
|------|----------|----------|
| 调价类 | 批量调价、批量涨价 | 商品管理查询返回空结果、调价 SKU 标识与规格不一致或无法匹配、销售价不高于成本或价格测算不通过、已有待审核草稿无法调价或重复发布、微信商品审核撤销或拒绝 |

### 6.8 风控二次确认

**TcRiskModal 组件**：
- 展示商品名称 + 风险说明（riskReason）
- 风险管控原因固定文案：`命中我司风险管控商品，该商品禁止上架`
- 操作按钮：「取消任务」/「继续上架」
- 通过 → confirmSub → 清风险态、校验节点全通过、店铺开始发布
- 拒绝 → rejectSub → 标记失败（failStep=1）、校验节点失败计数、店铺全部 failed
