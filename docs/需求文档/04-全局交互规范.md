# 品控中心 · 全局交互规范

> 跨模块沉淀的交互与样式规范，后续所有页面/模块默认遵守。

## 1. 筛选控件

- 全项目筛选下拉统一采用 40px 高的 BubbleSelect 样式，禁止原生 select 混用。
- 筛选语义统一「草稿/生效分离」：修改条件不即时过滤，点「查询/搜索」生效、「重置」恢复默认。

## 2. 条件与按钮同排布局

- 条件查询和按钮能放同一排的必须同排，放不下才允许换行。
- 「查询/搜索」固定最右，「重置」在其左；业务操作按钮（如批量分配/批量拒绝）在重置左侧。
- 按钮规格统一：40px 高、10px 圆角、8px 间距；按钮组占剩余网格列并右对齐（grid-column: 2 / -1; justify-content: flex-end），与上方条件列精确对齐。
- 危险操作按钮（批量拒绝等）浅红底红字，确认类 danger 按钮实心红。

## 3. 表格操作列

- 操作按钮最多直出两个 + 「更多」气泡（MoreActions，portal 弹泡，danger 项红色），竖向排列共三槽。
- 无操作的行显示 —，不空留。

## 4. 状态 tab 规范

- 列表页状态筛选优先用顶部 tab（带实时计数），tab 激活后表格不再重复展示状态列。
- 条件字段按当前 tab 智能显隐（无意义字段隐藏），专属字段（如拒绝原因）仅在对应 tab 出现。

## 5. 时间范围切换

- 趋势/统计区块统一按钮组：今日 / 近7天（或昨日/前3日/前7日）/ 自定义；自定义为触发器 + 日期区间弹层。
- 各区块范围状态独立，互不干扰。

## 6. 弹层规格

- Modal 三档：md / lg / xl（xl = 1080px, max-width 94vw），大图表类弹层用 xl。
- 弹层内表单沿用 BubbleSelect；危险确认用 danger 实心按钮。

## 7. 分享 HTML 纪律

- 独立分享页（Funion-品控中心.html）不主动重建/修改；功能改动一律先落源码（src/），本地 dev 即时生效；仅当用户点名要更新分享 HTML 时才重建，不确定先问。

## 8. 验证纪律

- 每次交付必须 tsc --noEmit 通过 + 浏览器实测（含控制台无 error）后汇报；窄屏换行仅在「放不下」时允许。
