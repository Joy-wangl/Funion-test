# 自动化中心 · 视频号全店搬家 · 产品与UI设计

> 项目：Funion（Vue3 SFC + TypeScript + Vite）
> 模块：智能运营中心 → 自动化中心 → 视频号全店搬家
> 性质：新模块从 0 到 1 设计（需求总结 → 设计规范回归 → 产品/UI 设计 → 闭环查验）

## 1. 需求总结（用户原始业务）

业务背景：视频号平台全店搬家。每个店铺可关联一个搬家任务，任务按自身配置自动实施；
平台已有策略模块（商品策略：默认发布策略 / 高利润策略），搬家任务复用策略作为发布规则载体。

用户明确的需求点：

1. **任务类型**：定时任务（一次性 & 长期）、条件触发任务、循环任务，共 3 类 4 形态；
2. **前置条件**：配置搬家任务、任务关联策略；二者就绪后才可执行；
3. **执行链路**：选择店铺 → 抓取（全店商品）→ 发布（到视频号目标店）；
4. **结果闭环**：有发布就必须有发布情况与反馈的展示（成功 / 失败原因 / 可重试）；
5. **店铺约束**：每个店铺只允许关联一个搬家任务；
5b. **多店搬家**：一个搬家任务的源店铺支持多选（可同时搬多个源店铺到同一视频号目标店），
    列表「搬家店铺」列堆叠展示多源店并标「共 N 个源店铺」；
5c. **条件化选品（非盲搬）**：搬家不按全店盲搬，按商品指标圈定与排序：
    排序（销量降序/订单数降序/上架最新优先/上架最久优先/综合降序）+
    过滤（近30日销量≥N / 累计订单≥N / 上架天数）+ 数量上限（全部/取前N款，按排序截断）；
    列表「选品规则」列直展摘要，抽屉独立分区配置；
5d. **列表定位（展示用配置清单）**：任务列表不承载执行过程信息——
    关联店铺只展数量（源 N → 目标 1，不展具体店名，明细在 Tab2）；
    执行规则、搬家进度不入列（条件触发任务无进度语义），执行与发布明细归 Tab3 执行批次；
6. **注意项**：模块内必须承载搬家业务的注意事项（风控 / 合规 / 核对类提醒）；
7. **落位**：智能运营中心 → 自动化中心（原导航占位项）下开模块，不允许天马行空，
   一切复用智能运营中心既有模块（店铺、策略、徽章、筛选、弹层）的标准化能力。

行业 grounding（参考资料，用于校准业务形态，非凭空设计）：

- 主流搬家工具（抖掌柜 / 牛牛搬家等）标准链路：店铺授权 → 搬家模板（定价 / 上架 / 图文 / 过滤）→
  整店抓取（全店或按销量筛选）→ 违规预检 → 分批推送目标店仓库 → 人工审核上架；
- 高频坑位（即「注意项」来源）：单批过量触发平台风控、跨平台原样搬运判盗图侵权、
  建议先入仓库草稿再人工上架、搬家后核对 SKU 映射防规格丢失；
- 微信小店侧已有「上架策略」概念，与本平台策略模块语义一致，任务关联策略成立。

## 3. 信息架构

```
智能运营中心
└─ 自动化中心（一级分组，新增二级导航）
   └─ 视频号全店搬家（MovePage）
      ├─ 注意项 notice 条（模块级，常驻）
      ├─ Tab1 搬家任务：任务列表 + 生命周期操作 + 配置抽屉
      ├─ Tab2 店铺关联：店铺 ↔ 任务 一一对应视角，未关联店一键配置
      └─ Tab3 发布反馈：执行批次 + 商品级发布状态与失败反馈 + 重新发布
```

业务主链路（闭环）：

```
配置搬家任务（类型/执行规则）──关联策略（前置）──关联店铺（前置，一店一任务）
        │ 启动 / 到点 / 触发 / 循环
        ▼
  执行批次（抓取全店商品）──套用策略（调价/图文/上架规则）──合规预检
        ▼
  商品级发布：入仓库 / 已上架 / 发布失败（原因+建议反馈）──失败可重新发布
        ▼
  批次与任务进度回写（抓取/成功/失败计数）──任务完成 / 暂停 / 长期继续
```

## 4. 页面与功能设计

### 4.0 注意项 notice 条（模块顶部常驻）

- ⚠ 图标 + 4 条：① 分批执行（默认 ≤50 款/批），单批过量易触发平台风控；
  ② 跨平台图文须经策略改写（标题清洗 / 图片去水印），原样搬运易判盗图侵权；
  ③ 建议先发布到仓库草稿、人工审核后再上架；④ 搬家完成后核对 SKU 映射，防规格体系差异丢 SKU。

### 4.1 Tab1 搬家任务

- 状态 chips（实时计数）：全部 / 未开始 / 进行中 / 已暂停 / 已完成；非「全部」隐藏状态列。
- 筛选：任务名称(input) / 任务类型(全部/定时/条件触发/循环) / 关联店铺 / 关联策略 + 新建搬家任务(primary) / 重置 / 查询。
- 列表定位：展示用配置清单，不承载执行过程信息（执行规则/具体店铺名/搬家进度不入列）；
  执行与发布明细归 Tab3 执行批次与商品级反馈。
- 列表列：任务信息(名称+ID) / 任务类型(徽章：定时-一次性、定时-长期、条件触发、循环) /
  选品规则(排序主行 + 过滤·截断副行，tooltip 全量摘要) /
  关联店铺(仅数量：源 N → 目标 1 + 共 N+1 个关联店铺，不展具体店名) /
  关联策略 / 状态(徽章) / 创建时间 / 操作。
- 生命周期状态机：未开始 →(启动) 进行中 →(暂停) 已暂停 →(启动) 进行中 →(跑完) 已完成；
  操作按状态生成：未开始[启动,编辑,更多:删除]、进行中[详情,暂停,更多:删除]、
  已暂停[启动,编辑,更多:删除]、已完成[详情,编辑,更多:删除]；删除=强提醒二次确认。
- 详情 → 跳 Tab3 并按该任务过滤执行批次。

### 4.2 配置抽屉（新建 / 编辑搬家任务，右滑 640px，三步向导）

步骤条三步：① 选源店铺 → ② 执行条件与策略 → ③ 发布设置；抽屉尺寸固定，步骤切换仅换 body 内容（步内滚动）；
foot 按钮随步：取消常驻、上一步(step≥2)、下一步(step≤2，primary) / 保存任务(step3，primary)；
「下一步」先校验当前步必填，未过 error toast 拦截：

1. 步骤1 选源店铺：任务名称*；源店铺*（复选多选列表，一个任务可同时搬多个源店；平台 logo+店名；
   已被其它任务占用的店置灰并标「已关联：任务名」，落实一店一任务）。
2. 步骤2 执行条件与策略：
   - 执行条件*：任务类型（三张 radio 卡：定时/条件触发/循环，带说明）；定时→执行方式(一次性/长期)+时间；
     条件触发→触发条件（源店上新商品/源店商品上架/源店价格调整/源店库存变化）；循环→间隔(每 N 小时/天)；
   - 选品规则（搬家非盲搬）：商品范围（全店商品/仅有动销商品 + 剔除已下架）；商品排序（销量降序/订单数降序/上架最新优先/上架最久优先/综合降序）；
     过滤条件（近30日销量≥N、累计订单≥N、上架天数 不限/近30天/近90天/超180天）；搬家数量（全部/取前N款，按排序截断）；
   - 策略与关联店铺*：发布策略 BubbleSelect（默认发布策略/高利润策略）；关联店铺（视频号单选，发布落地店、策略在该店生效，占用置灰）。
3. 步骤3 发布设置：发布方式（发布到仓库/直接上架，推荐仓库）；分批大小（款/批，默认 50）；合规预检勾选（默认开）；
   配置回看灰底块（任务/源店铺/落地店·策略/执行/选品 摘要）；注意项灰底块（同 4.0 四条）。

### 4.3 Tab2 店铺关联

- 说明条：每个店铺仅可关联一个搬家任务，关联后按任务配置自动执行。
- 筛选：店铺名称(input) / 平台 / 关联状态(全部/已关联/未关联) + 重置 / 查询。
- 列表列：店铺信息(logo+名称+店铺ID) / 平台 / 店铺状态(在线绿点/离线灰点) / 关联搬家任务 / 任务状态 / 操作。
- 操作：未关联→「配置搬家任务」（开抽屉并预填该店：平台=视频号预填目标店，否则预填源店）；
  已关联→「查看任务」（跳 Tab1 过滤）+ 更多[发布反馈]（跳 Tab3 过滤）。

### 4.4 Tab3 发布反馈

- 筛选：所属任务 / 发布状态(全部/发布中/入仓库/已上架/发布失败) / 商品名称 + 重置 / 查询。
- 上卡·执行批次表：批次ID / 所属任务 / 触发方式(定时/条件/循环/手动 徽章) / 开始时间 / 结束时间 /
  抓取数 / 发布成功 / 发布失败 / 状态；行点选（高亮）联动下卡，默认选中最新批次。
- 下卡·商品发布明细表：商品信息(图+标题+源店) / SKU数 / 抓取状态(已抓取徽章) /
  发布状态(徽章：发布中橙/入仓库蓝/已上架绿/发布失败红) / 失败原因与反馈(原因+处理建议，成功行 —) /
  操作（失败行[重新发布,商品详情]，成功行[商品详情]）。
- 重新发布 → 该行回「发布中」+ toast，闭环可重试。

## 5. UI 规格

- 根容器复用 `.sg-page` 体系（sg-tabs/sg-chip/sg-filter/sg-grid/sg-card/sg-table/sg-btn/sg-input），
  新增样式统一 `mv-` 前缀（Move.css），徽章复用 badge-green/orange/red/gray，新增 mv-badge-blue（入仓库）。
- 任务类型徽章色：定时-一次性=blue、定时-长期=green、条件触发=orange、循环=gray；
  任务状态：未开始=gray、进行中=blue、已暂停=orange、已完成=green；发布状态同 4.4。
- 抽屉：右滑 640px、白底、分区标题 13px 加粗、foot 吸底（取消/保存任务 primary）。
- notice 条：浅橙底 + ⚠ + 12px 文案，四条横排自动换行。
