## 模块定位

品控中心以「问题类型驱动 · 系列编码追踪」为主线：

1. **数据概览**：全局问题分布与趋势，发现风险；
2. **监控列表**：系列编码维度的问题明细与平台下钻，定位风险；
3. **优化任务**：命中问题的垃圾品发起优化闭环（待认领 → 待优化 → 优化中 → 待审核 → 优化完结 / 拒绝），并通过趋势图区间带验证优化效果。
