# 品控中心 · 优化任务

> 页面入口：品控中心 → 优化任务（侧边栏第三项）
> 涉及文件：src/pages/quality/qcOptData.ts、qcOptPage.tsx、QualityCenter.tsx、qcCenter.css

## 1. 背景与状态机

针对命中问题的垃圾品建立优化闭环：

```
待认领 → 待优化 → 优化中 → 待审核 → 优化完结
        └→ 拒绝
```

- 待认领：任务登记未分配；分配后进入待优化；进入优化中记录 optStartAt；优化完成（提交审核/完结）记录 optEndAt。
- 数据层 qcOptData.ts：OptTask 模型（系列编码/状态/优化类型/方向/级别/选品人/近一个月订单/毛六/发退率/组别/分配状态/分配运维/分配时间/拒绝原因/optStartAt/optEndAt）。

## 2. 状态 tab 置顶

- 顶部 tab：全部 + 六状态，实时计数；tab 即状态筛选，故筛选区不再设「优化状态」条件。
- 字段按状态智能显隐：
  - 待认领 tab：隐藏「分配运维」筛选（无意义），表内分配运维/分配时间显示 —；
  - 优化状态列：仅「全部」tab 展示（具体 tab 下不重复）；
  - 拒绝原因列：仅「拒绝」tab 展示。

## 3. 字段取舍决策

参考业务截图裁剪：去掉主卖平台、优化完结时间、优化结果、竞品利润列及原顶部统计块；保留并新增状态 tab。

## 4. 筛选面板与按钮布局

- 条件：生成开始/结束时间、选品人、系列编码、运维组别、优化级别、优化方向、分配状态。
- 末行条件与按钮同排：分配状态占第 1 列，按钮组占剩余列右对齐——批量分配/批量拒绝在左，重置/搜索最右（搜索最右）。
- 批量分配/批量拒绝仅在「全部」「待认领」tab 显示（其余状态无可批量操作的任务）；勾选后按钮左侧出现「已选 n 条待认领任务」提示。
- 按钮规格统一：40px 高 / 10px 圆角 / 8px 间距；批量拒绝浅红底红字。

## 5. 表格列顺序（按维度与重要性）

复选框｜系列编码｜优化状态(全部)｜优化级别｜优化类型｜发退率｜近一个月订单｜近一个月毛六｜优化方向｜分配状态｜分配运维｜运维组别｜分配时间｜选品人｜登记日期｜拒绝原因(拒绝)｜操作。

分组逻辑：对象 → 状态/优先级 → 问题与业务影响 → 执行分配 → 来源 → 操作。

## 6. 行操作

- 仅待认领行有操作：编辑 / 分配 / 更多（删除、拒绝）——遵守「操作列最多直出两个 + 更多气泡」竖排三槽规范，更多项红色 danger。
- 其它状态行操作列显示 —。

## 7. 弹层闭环（id 驱动，单条与批量共用）

- 批量分配：选择分配运维 + 运维组别 → 待认领转待优化，写入分配运维/组别/分配时间。
- 批量拒绝：填写拒绝原因 → 转拒绝。
- 删除任务：danger 确认弹层。
- 编辑任务：优化方向/级别/组别/选品人四个下拉。

## 8. 联动与后续

- 数据概览「优化数据概览」状态卡点击 → 本页对应 tab 激活；本页操作后概览计数同步。
- 趋势图优化效果区间带读取本页任务的 optStartAt/optEndAt。
- 后续规划（未启动）：发起入口（监控列表/TOP 榜挂「优化任务」按钮）、优化效果验证对比卡（优化前后指标对比 + 数据驱动验收）。
